关于本项目

本项目以百度 2018 AI 竞赛的植物病害数据集训练 MobileNetV2 多分类模型，结合大语言模型（LLM）生成针对性的治理建议。

功能流程

  1. 上传作物叶片照片
  2. 模型推理 → 植物种类 / 健康状况 / 病害类型 / 患病程度
  3. 调用 LLM → 生成防治方案

支持的 LLM 提供商

  • OpenAI（gpt-3.5-turbo 等）
  • 百度文心一言
  • 阿里通义千问（推荐，DashScope）
  • Mock（本地测试，无需 API Key）
